## 🏠 Proyecto actual: Home Lab

Laboratorio doméstico de infraestructura montado sobre **VMware**, pensado como práctica de administración, monitoreo y automatización de sistemas reales.

| Componente | Uso |
|---|---|
| Ubuntu Server + PNetLab | Base de virtualización y laboratorio de redes |
| Zabbix + Grafana | Monitoreo de infraestructura y dashboards |
| Docker | Contenedores para los servicios del lab |
| n8n + bot de Telegram | Automatización y alertas con IA |
